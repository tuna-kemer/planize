# Planize

A personal planner that keeps your tasks, notes and boards in one place and syncs them across your devices.

## Features

- Tasks, notes and vision boards
- Cross-device sync with Firebase Firestore
- Works offline and syncs when the connection returns
- Email and password sign-in
- Installable to the home screen; works on desktop and tablet

## Tech stack

- HTML, CSS, JavaScript (single-file app, no build step)
- Firebase Authentication and Firestore
- Hosted on GitHub Pages

## Privacy

The app itself is public, but your data is not. It is stored in Firebase and protected by security rules, so only the account owner can read or write it.
